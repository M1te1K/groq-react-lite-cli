# Проверки поставки

Дата: 16 октября 2026 года. Python 3.12.15, uv 0.13.1, Groq SDK 0.37.1; версии зависимостей зафиксированы в `uv.lock`.

## Автоматические проверки

Перед подготовкой публикации на macOS arm64 повторены 105 тестов и `ruff check .`: все прошли. Тесты работают без сети и настоящих ключей. Они проверяют:

- Decimal-арифметику, валидацию и деление на ноль;
- XML ЦБ, кодировку, номинал, запрошенную и фактическую даты;
- передачу результата первого инструмента во второй, историю и `/reset`;
- настоящий Groq SDK с контролируемым HTTP-транспортом: 401/429/5xx, повторы, ошибки и дедлайн;
- лимиты шагов и вызовов, корректное продолжение после ошибки;
- компактный вывод до инструмента, один итоговый ответ, TTY/NO_COLOR;
- полные JSONL-события и маскирование значений секретов с сохранением имён полей.

Команды для повторения:

```sh
uv sync --frozen --no-editable
uv run --frozen --no-editable pytest
uv run --frozen --no-editable ruff check .
```

## Реальные API

При разработке отдельно проверен установленный CLI с Groq (`openai/gpt-oss-120b`) и Банком России: конвертация 500 USD, продолжение про 1000 USD, `/reset` с последующим уточнением и запрос курса EUR. Подтверждены отдельные получение данных и расчёт, сумма, фактическая дата и ссылка на ЦБ, компактные действия и один итоговый ответ. Это ручные сценарии на настроенном аккаунте, а не часть автономных тестов или гарантия для произвольных запросов и других аккаунтов.

## Чистая установка перед публикацией

В новую временную папку скопирован только состав поставки: 29 файлов, без исходных `.venv`, `.env`, журналов и кэшей. `uv sync --frozen --no-editable --offline` собрал и установил wheel с зависимостями из локального кэша; повторная загрузка пакетов из интернета в этой проверке не выполнялась.

Затем выполнены команды README: `uv run --frozen --no-editable pytest` — **105 passed**, `uv run --frozen --no-editable ruff check .` — **All checks passed**. Все 11 установленных Python-модулей побайтно совпали с исходниками.

Шаблон `.env.example` скопирован в новый `.env` без ключа. В обычном режиме и с `--trace` проверены `/help`, понятный ответ при отсутствии ключа, `/reset`, `/exit`, код выхода 0, отсутствие traceback, технических дампов и ANSI при перенаправлении. Отдельно проверены `react-lite --help`, `python -m react_lite`, EOF и структура записанного JSONL. Исходники и локальный `.env` рабочей установки при подготовке поставки не изменялись.

## Ограничения

- Общий дедлайн требует POSIX и главного потока: Linux, macOS или WSL с Linux; нативная Windows не поддерживается.
- История хранится в памяти процесса без автоматического сжатия; `/reset` очищает её, но не удаляет журнал.
- У источника курса нет резерва. При недоступности ЦБ возвращается ошибка.
- Dockerfile подготовлен. При проверке поставки Docker-клиент не смог подключиться к движку; сборка и запуск контейнера не подтверждены.
- GitHub Actions проверяет Linux и macOS без настоящих API-ключей; актуальный результат доступен во вкладке Actions репозитория.
